The Cybersalt Extension Manager installs, updates and looks after every Cybersalt extension on your site from one screen. It's free.

Installing it

  1. Download pkg_csextensionmanager from cybersalt.com.
  2. In your site's administrator, go to System → Install → Extensions and upload the zip.
  3. Click Open the Extension Manager on the card that appears, or go to Components → Cybersalt Extension Manager.

It needs Joomla 5 or 6 and PHP 8.1 or later, and your site has to be able to reach www.cybersalt.com.

The Extensions screen

Every Cybersalt extension and MCP for Joomla add-on is listed, in four groups:

  • Needs attention: updates you haven't installed yet, and anything that's only half installed.
  • Installed and up to date.
  • More Cybersalt extensions: ones not on your site yet.
  • MCP for Joomla add-ons: the ones for extensions you already have are marked.

The numbers at the top are filters: click Updates to see only the extensions with an update. You can also search, filter by status, kind (extension or add-on) and licence (free or Pro), or show only the add-ons for extensions on your site. Your filters are remembered next time.

Installing and updating

Click Install or Update to x.y.z on a card. To do several at once, tick them (hold Shift to tick a range) and click Install / update selected, or click Update all in the toolbar. A window shows each one as it goes; keep it open until it says it's done. If one fails, the rest still go ahead and the window says why it failed.

If an MCP add-on needs MCP for Joomla and it isn't installed, MCP for Joomla is installed first, automatically.

Every download comes from cybersalt.com and is checked against the checksum published with the release before anything is installed.

What's new, and going back to an earlier version

What's new (or Changelog) shows the release notes, with every release newer than yours marked. If an update causes trouble, open More → Install another version… and pick the release to go back to.

Switching parts on and off, uninstalling

Packages list their parts under N parts on the card, each with an on/off switch. More → Uninstall removes an extension; if other installed add-ons depend on it, you're told which before anything happens.

Pro extensions

Free extensions install without an account. For Pro extensions, the site needs your Cybersalt download ID. There are three ways:

  • Activate this site on the Extensions screen with the email address of your cybersalt.com account. cybersalt.com sends you an email to confirm.
  • If MCP for Joomla is already activated on the site, its activation is used automatically.
  • Paste a download ID under Options → Account.

The download ID is also added to every Cybersalt update site, so Joomla's own System → Update → Extensions screen can download Pro updates too.

Health Check

The Health Check finds the things that quietly stop updates from arriving and fixes them with one click:

  • an extension with no update site, or one that's switched off, points somewhere else, or has duplicates;
  • a Pro extension whose update site doesn't carry your download ID;
  • a package that's only half installed, or parts of a package installed without the package;
  • parts that are switched off;
  • MCP add-ons without MCP for Joomla, or for an extension that isn't on the site;
  • updates Joomla still lists after you installed them;
  • a lapsed membership, or cybersalt.com not answering.

Fix all repairs update sites and download IDs in one go. Installing and switching things on are left for you to choose one by one.

Update checks and email

Installing the Extension Manager adds a scheduled task that checks for Cybersalt updates once a day and emails Super Users (who receive system emails) when something new is available. Change it under System → Scheduled Tasks → Cybersalt Extension Manager: check for updates:

  • Install updates: no (just let me know), patch releases only, patch and minor releases, or all.
  • Email a summary: when something changed, every run, or never.

Who gets the email, and which extensions are never updated automatically, are set under Options → Updates. The Extension Manager never updates itself from the task.

The Home Dashboard also shows the number of Cybersalt updates next to Joomla's own update checks.

History

History lists every install, update, rollback, uninstall, health fix, update check and email: who did it, what changed, and how long it took. Filter by any column, download it as CSV, or click Dump for plain text to paste into a support request.
