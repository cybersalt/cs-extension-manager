Cybersalt Extension Manager installs, updates and looks after every Cybersalt extension on your Joomla site from one screen. You see what's installed, what has an update and what you don't have yet; install or update one extension or all of them in one go; read what changed since your version; go back to an earlier release if an update causes trouble; and let a daily check email you when something new is out. It's free.

Release history. This page documents the current release. For what changed in each version, see the changelog.

Requirements. Joomla 5 or 6 and PHP 8.1 or newer. Your site has to be able to reach www.cybersalt.com over https. Extension Manager is free and open source (GPL-2.0-or-later); the source is on GitHub.

Installing

  1. Download pkg_csextensionmanager_v*.zip from cybersalt.com.
  2. In your Joomla admin go to System → Install → Extensions and upload the zip. The three plugins are switched on for you.
  3. Click Open the Extension Manager on the card that appears, or go to Components → Cybersalt Extension Manager.

If you'd like an email when a new release of a Cybersalt extension on your site is out, click Email me about new releases on the same card. Release emails are off until you ask for them; see Release emails and automatic updates.

Extension Manager updates itself like any Cybersalt extension: from its own Extensions screen, or from System → Update → Extensions.

The Extensions screen

Every Cybersalt extension and MCP for Joomla add-on is listed as a card, in four groups:

GroupWhat's in it
Needs attention Updates you haven't installed yet, and anything that's only half installed.
Installed and up to date Cybersalt extensions on this site running the latest version.
More Cybersalt extensions The ones not on this site yet.
MCP for Joomla add-ons Add-ons that let AI apps work with other extensions through MCP for Joomla. The ones for extensions you already have are marked.

Each card shows the installed and latest versions, the release date, whether it's free or Pro, what kind of extension it is, and anything the latest release needs that this site doesn't have (a newer Joomla or PHP, for example). Packages list their parts under N parts.

The numbers along the top are filters: click Updates to see only the extensions with an update. You can also search by name or description, filter by status, kind (extensions or add-ons) and licence (free or Pro), or tick Only add-ons for extensions on this site. The browser remembers your filters for next time.

Check for updates in the toolbar asks cybersalt.com again straight away. Otherwise the list is reused for six hours (change this under Options → Catalog).

Installing and updating extensions

  1. Click Install or Update to x.y.z on a card.
  2. To do several at once, tick their boxes (hold Shift to tick a range, or use Select all updates) and click Install / update selected. Or click Update N extensions in the toolbar.
  3. A window lists each one as it goes. Keep it open until it says All done, then click Done, reload the page.

If one fails, the rest still go ahead, and the window says why that one failed. If an MCP add-on needs MCP for Joomla and it isn't installed, MCP for Joomla is installed first, automatically.

Every download is checked before it's installed. Extension Manager only installs from cybersalt.com over https, compares each download with the SHA-256 checksum published with the release, and checks that the zip contains the extension you asked for. If cybersalt.com can't be reached to confirm the latest release, nothing is installed.

What's new, and going back to an earlier version

What's new (or Changelog when you're up to date) opens the release notes, with the version installed here marked. If an update causes trouble, open More → Install another version… on the card, or use the Install x.y.z button next to an older release in the changelog, to go back to it.

Switching parts on and off, uninstalling

Open N parts on a package's card to see each component, module and plugin in it, each with an on/off switch. More → Uninstall removes an extension. If installed add-ons depend on it (uninstalling MCP for Joomla, for example), you're told which ones will stop working and asked to confirm first.

Pro extensions

Free extensions install without an account. For Pro extensions, the site needs your Cybersalt download ID. There are three ways to give it one:

  • Activate this site on the Extensions screen with the email address of your cybersalt.com account. This sends the site's domain and your email address to cybersalt.com, which emails you to confirm.
  • If MCP for Joomla is already activated with a Pro membership on this site, its activation is used automatically, so the site isn't registered twice. (You can turn this off under Options → Account.)
  • Paste a download ID under Options → Account → Download ID, if Cybersalt gave you one for this site. It takes priority over the other two.

The download ID is also written onto every Cybersalt update site, so Joomla's own System → Update → Extensions screen and remote managers such as mySites.guru can download Pro updates too. If the update sites are rebuilt, the installer plugin adds it back to the download.

Health Check

The Health Check finds the things that quietly stop updates from arriving, and fixes most of them with one click. It looks for:

  • an extension with no update site, or one that's switched off, points somewhere other than cybersalt.com, or has duplicates;
  • update sites left behind by extensions that are no longer installed;
  • a Pro extension whose update site doesn't carry your download ID;
  • a package that's only half installed, or parts of a package installed without the package (they never get updates);
  • parts that are switched off;
  • MCP add-ons without MCP for Joomla, or for an extension that isn't on the site;
  • updates Joomla still lists after you've installed them;
  • a lapsed membership, or cybersalt.com not answering.

Each finding is a Problem, a Warning or Good to know, with a button to fix it where there is one. Fix all repairs the update sites and download IDs in one go; installing and switching things on are left for you to choose one by one.

Release emails and automatic updates

Extension Manager adds a scheduled task, Cybersalt Extension Manager: check for updates, that runs once a day. It's switched off when you install. Click Email me about new releases on the install card or at the top of the Extensions screen to switch it on; the emails then go to you (or to the addresses under Options → Updates, if you've set any).

To change what the task does, go to System → Scheduled Tasks and open Cybersalt Extension Manager: check for updates:

SettingChoices
Install updates No, just let me know (the default); Patch releases only (1.2.3 → 1.2.4, fixes only); Patch and minor releases (1.2.3 → 1.3.0); or All updates, including major releases.
Email a summary When something changed or is newly available (the default), Every run, or Never.

The task never updates Extension Manager itself (update it from its own screen), skips anything listed under Options → Updates → Never auto-update, and skips updates this site's Joomla or PHP version can't run. Every run is recorded in History.

Joomla runs scheduled tasks when someone visits the site, unless you've set up the web cron or a server cron job under System → Scheduled Tasks → Options. On a quiet site, a real cron job makes the daily check run on time.

History

History lists every install, update, rollback, uninstall, part switched on or off, health fix, update check and email: when, who, which versions, what happened and how long it took. Filter by any column, search, download it as CSV, or click Dump for plain text to paste into a support request. Installs, updates, rollbacks and uninstalls also go to Joomla's own User Actions Log.

Troubleshooting

SymptomCause and fix
"Couldn't reach cybersalt.com" or "Couldn't check the latest release" The site can't make outgoing https requests to www.cybersalt.com. Ask your host to allow it, or raise Connection timeout under Options → Catalog if the connection is slow.
A Pro extension says you don't have access Activate the site (or check the email you activated with is the one on your cybersalt.com account), then click Check for updates. The account panel shows whether the membership is active or lapsed.
An update isn't offered The card says when the latest release needs a newer Joomla or PHP than this site has. Beta releases are only offered with Offer beta releases on.
Joomla's Update screen doesn't show Cybersalt updates Run the Health Check: a missing, switched-off or duplicate update site is the usual cause.
No release emails Check that the scheduled task is enabled, that it has run (System → Scheduled Tasks shows the last run), and that the site can send email (System → Global Configuration → Server → Send Test Mail).

Getting help

Questions and bug reports are welcome through the Cybersalt support form.

You'll get the quickest answer if you include your Joomla and PHP versions, the Extension Manager version, the extension involved and, for install or update problems, the text from History → Dump.
