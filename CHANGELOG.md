# Changelog

All notable changes to Cybersalt Extension Manager are documented here. Only released versions are listed, plus the version in progress. People whose ideas or reports shaped a change are credited on that entry.

## [0.1.0] - Unreleased

### 🚀 New
- **Every Cybersalt extension in one place.** The Extensions screen lists every Cybersalt extension and MCP for Joomla add-on with what's installed here, the latest version, its release date and whether it's free or Pro, with search, filters (status, kind, licence, "only add-ons for extensions on this site") and clickable stat cards. Filters are remembered per browser.
- **One-click install, update, repair and reinstall**, one at a time or in bulk ("Update all", or tick several with shift-click ranges). A lock-out window shows each item's progress live and the reason when one fails, carries on with the rest, and can't be closed halfway.
- **Dependencies handled.** Installing an MCP add-on installs MCP for Joomla first when it isn't there, and uninstalling MCP for Joomla warns which add-ons would stop working.
- **Downloads are checked before installing.** Only https downloads from the Cybersalt store are accepted, the latest release is checked against the SHA-256 checksum in the update feed, and the zip has to contain the extension that was asked for.
- **What's new since your version.** The changelog window highlights every release newer than the one installed.
- **Roll back to any earlier release** from the changelog window ("Install another version").
- **Compatibility checked first.** Updates this site's Joomla or PHP version can't run are flagged and not offered.
- **Health check with one-click fixes**: missing, switched-off, duplicate, wrong or orphaned update sites; a missing download ID on Pro update sites; half-installed packages; package parts installed without their package (so they never get updates); disabled parts; add-ons without MCP for Joomla or without the extension they're for; updates Joomla still lists after they were installed; a lapsed membership; and the store not answering. "Fix all" repairs the update-site bookkeeping in one go.
- **Pro extensions**: activate the site with a cybersalt.com account email, paste a download ID in Options, or reuse MCP for Joomla's existing Pro activation automatically. The download ID is written onto every Cybersalt update site, so Joomla's own System → Update screen can download Pro updates too, and an installer plugin adds it back if update sites are rebuilt.
- **Home Dashboard quick icon** with the number of Cybersalt updates, fetched after the dashboard loads so it never slows it down.
- **Release emails, opt-in.** "Email me about new releases" on the install screen and the Extensions screen switches on a daily scheduled check that emails you when something new is out (off until you ask). The same task can also install updates automatically, limited to patch releases, patch and minor releases, or all. Extensions can be excluded from automatic updates; the Extension Manager never updates itself from a task.
- **History**: every install, update, rollback, uninstall, enable/disable, health fix, update check and email, with the standard Cybersalt log viewer (filters for every column, CSV download, text dump for support, delete and clear all). Installs, updates and uninstalls also go to Joomla's User Actions Log.
- **Dashboard.** The manager opens on a dashboard: big Extensions, Templates, Health Check and History tiles, what needs updating (with Update all), recent activity, your Cybersalt account, and a few templates that change each day. A section bar at the top of every screen (Dashboard, Extensions, Templates, Health Check, History) gets you anywhere in one click, and the same entries are in Joomla's side menu.
- **Templates.** A Templates screen shows the Joomla templates from Energize Themes and VirtueMart Templates: a thumbnail, who each one is for, the Joomla versions and shop extension it supports, a live demo link and its details page. Filter by type (the same template types the two sites use, such as Business, Technology, Fashion or Electronics), template site, Joomla version and shop, search, and sort by name, site or newest Joomla; each site has a "See plans" button. The list comes from cybersalt.com and is rebuilt every night from both sites' catalogs, so a new template appears the next day without an Extension Manager update; a copy ships with the extension in case cybersalt.com can't be reached. Nothing is installed from here, and only links to Cybersalt's own sites are shown. (Idea from Bjørn Ove Bremnes.)
- **Extensions as a sortable list.** One row per extension, easy to read top to bottom: name and a one-line description, status, installed and latest version. Click a column heading to sort by name, status, installed version or release date (remembered per browser). Each row has one main button (Install / Update / Repair) and everything else under More; click the name to open its details (full description, parts with on/off switches, notes). A "Showing N of M" line follows the filters.
- Enable or disable each part of an installed package from its card. Hovering a switch says what a click will do ("Click to disable"), and the result shows as a small "✓ Disabled" note right beside it: no page reload, no message at the top of the page, no jump when you're scrolled down.
- **Tick and go, in bulk.** Every row can be ticked, and a checkbox in the table heading selects every extension the filters show. Three buttons act on what's ticked: **Install / update selected**, **Reinstall selected** (the latest release over itself, settings kept) and **Uninstall selected** (add-ons go before MCP for Joomla). Each button counts only the ticked rows it applies to. The Extension Manager itself can't be ticked.
- **Click anywhere on a row** to open its details, and a bigger round arrow shows each row opens.
- **Health check:** an add-on whose extension isn't on the site (say MCP for VirtueMart without VirtueMart) gets an Uninstall button on its card, and the wording says plainly that it has nothing to work with. (Tim's review, 12 Nov 2026.)
- **Health count matches the Health Check page.** The dashboard tile, the section bar badge and the Extensions count now include every issue the Health Check lists, notes included. The Health Check tile is green with nothing to look at, yellow for warnings or notes ("Notes only, nothing broken" when it's just notes), and red only for real problems. (Tim's review, 13 Nov 2026.)
- **Hide a "Good to know" note** you don't need (a part you switched off on purpose, an add-on you're keeping). Hidden notes leave the counts and Fix all, and sit under "Hidden notes" at the bottom of the Health Check, where each can be shown again (or all at once). Warnings and problems can't be hidden.
- The heart on the Health Check tile sits in the middle of its circle.
- The section bar is a soft grey instead of bright white, and the sections you're not on read as plain text instead of light-blue links.
- Confirm and progress windows have their padding back (Joomla's admin template was zeroing it), and a package's parts sit in two even columns with each switch's hover hint above its own switch.
- Options: download ID, MCP for Joomla activation reuse, how often to check, which MCP add-ons to show, beta releases, timeout, email recipients, auto-update exclusions, history retention, support contact details and permissions (view / install / fix).

### 🔍 Security
- Packages are only installed from cybersalt.com, over https. Redirects are followed one hop at a time: never to plain http, and away from cybersalt.com only when a published checksum will verify the bytes. Nothing is installed when the latest release can't be checked with the store first.
- The store address can't be changed from Options (only in code, for development), so permission to change Options never becomes permission to choose what gets installed.
- Every action checks the form token and a permission (view / install / fix); installing also needs access to Joomla's own Extensions Manager. A request can only name an extension from the catalog, never a download address, file or arbitrary extension id.
